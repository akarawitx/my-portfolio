# My Portfolio — Akarawit Juntarang

เว็บไซต์ผลงานส่วนตัว (Personal Portfolio) สำหรับสมัครงานตำแหน่ง Web Developer พัฒนาด้วย **Vue 3** + **Vite** ในรูปแบบ **Single Page** (หน้าเดียว เลื่อนดูทุกส่วนต่อกัน) ดีไซน์สไตล์ **Neo-Brutalism** ขอบหนา เงาแข็ง โทนสีฟ้า–น้ำเงิน–ขาว–ดำ เนื้อหาทั้งหมดเป็นภาษาไทย

---

## ✨ จุดเด่น

- **บัตรพนักงานห้อยสายคล้อง** ที่ค้างอยู่ด้านซ้ายขณะเลื่อนดูหน้าแรกและประวัติการศึกษา แกว่งเบาๆ ได้
- **เมนูปรับตามขนาดจอ** จอกว้างเป็นแถบด้านข้าง จอแคบเป็นแถบด้านบนพร้อมเมนูแฮมเบอร์เกอร์ และไฮไลต์ปุ่มตามส่วนที่กำลังดูอยู่
- **ส่วนผลงาน** มีตัวกรองตามประเภท การ์ดโปรเจกต์ และหน้าต่างรายละเอียดที่ดูภาพหน้าจอ ซูม และลากภาพได้
- **ฟอร์มติดต่อ** ส่งอีเมลจาก frontend ได้เลยผ่าน EmailJS ไม่ต้องมี backend
- **รองรับมือถือ** และเคารพการตั้งค่าลดแอนิเมชัน (`prefers-reduced-motion`)

| ส่วน | เทคโนโลยี |
|---|---|
| Framework | Vue 3 (Composition API + `<script setup>`) |
| Build Tool | Vite |
| ส่งอีเมลจากฟอร์ม | EmailJS (`@emailjs/browser`) |

## 📁 โครงสร้างโปรเจกต์

```
src/
├── App.vue                  # Root — ประกอบทุกส่วนเป็นหน้าเดียว + CSS variables ส่วนกลาง
├── main.js                  # จุดเริ่มต้นแอป
├── assets/                  # รูปโปรไฟล์ โลโก้ และภาพหน้าจอผลงาน
│   └── project/             # แยกโฟลเดอร์ตามโปรเจกต์ (eLibrary, FunFoods, seniorProject ฯลฯ)
└── components/
    ├── Header.vue           # เมนูหลัก (แถบข้าง / แถบบน + แฮมเบอร์เกอร์)
    ├── HeroSection.vue      # หน้าแรก + บัตรพนักงาน (รวม EducationSection ไว้ในกริดเดียวกัน)
    ├── EducationSection.vue # ประวัติการศึกษา
    ├── SkillsSection.vue    # เครื่องมือและเทคโนโลยีที่ใช้
    ├── ProjectsSection.vue  # ผลงาน: ตัวกรอง การ์ด หน้าต่างรายละเอียด
    ├── ContactSection.vue   # ข้อมูลติดต่อ + ฟอร์มส่งข้อความ
    ├── Footer.vue           # ส่วนท้ายเว็บไซต์
    └── AboutSection.vue     # (ยังไม่ได้ใช้งานในหน้า)
```

> เวอร์ชันก่อนหน้าเป็นหลายหน้าด้วย Vue Router (`pages/` และ `router/`) ตอนนี้ยุบเป็นหน้าเดียวและลบทั้งสองโฟลเดอร์ออกแล้ว

## 🧭 อธิบายแต่ละ Component

### `Header.vue`
เมนูหลักที่มี 2 รูปแบบในไฟล์เดียว สลับกันด้วย media query

- **แถบด้านข้าง (`.rail`)** แสดงเมื่อจอกว้าง ≥ 1200px **และ** สูง ≥ 600px ประกอบด้วยรูปโปรไฟล์ ปุ่มเมนู และปุ่มดาวน์โหลด CV
- **แถบด้านบน (`.topbar`)** แสดงในกรณีอื่น มีโลโก้และปุ่มแฮมเบอร์เกอร์ที่เปิดเมนูแบบเลื่อนลง (กด `Esc` เพื่อปิดได้)
- ใช้ `IntersectionObserver` ตรวจว่ากำลังดูส่วนไหนอยู่ เพื่อไฮไลต์ปุ่มเมนูให้ตรงกัน
- ข้อมูลเมนูอยู่ในอาร์เรย์ `links` และรายชื่อ section ที่ตรวจอยู่ใน `sectionIds` ถ้าเพิ่มหรือลบส่วนในหน้า ต้องแก้ทั้งสองที่นี้

### `HeroSection.vue`
ส่วนแรกของหน้า แบ่งเป็นสองคอลัมน์

- **ซ้าย:** บัตรพนักงานห้อยสายคล้อง ใช้ `position: sticky` เพื่อให้ค้างอยู่ขณะเลื่อน
- **ขวา:** ข้อความแนะนำตัว ปุ่มดูผลงาน/ดาวน์โหลดเรซูเม่ และ `EducationSection` ซ้อนอยู่ข้างใน ทำให้บัตรค้างต่อเนื่องไปตลอดสองส่วนนี้
- ใช้ `overflow: clip` (ไม่ใช่ `hidden`) ที่ `.hero` เพราะ `hidden` จะทำให้ sticky ใช้ไม่ได้

### `EducationSection.vue`
การ์ดประวัติการศึกษา ข้อมูลอยู่ในอาร์เรย์ `education` (สถานศึกษา สาขา สถิติ และสิ่งที่ได้เรียนรู้) เพิ่มรายการใหม่ได้โดยเพิ่ม object ในอาร์เรย์นี้ พื้นหลังสีครีมขยายเต็มความกว้างจอด้วยเทคนิค `box-shadow` + `clip-path`

### `SkillsSection.vue`
แสดงเครื่องมือแยกเป็นหมวด (ภาษาโปรแกรม, Frontend, Backend, Database, Tools) ข้อมูลอยู่ในอาร์เรย์ `groups` ไอคอนดึงจาก Icons8 ถ้ารูปโหลดไม่ขึ้นจะแสดงตัวย่อในกรอบสีแทนอัตโนมัติ

### `ProjectsSection.vue`
- ข้อมูลโปรเจกต์ทั้งหมดอยู่ในอาร์เรย์ `allProjects`
- **ตัวกรอง** ทั้งหมด / เว็บแอปพลิเคชัน / ออกแบบ UX/UI
- **การ์ดโปรเจกต์** แสดงภาพตัวอย่าง ป้ายสถานะ คำอธิบายสั้น ป้ายเทคโนโลยี และไอคอนลิงก์ (GitHub, เว็บจริง, Figma, Google Drive)
- **หน้าต่างรายละเอียด** ดูคำอธิบายเต็มและแกลเลอรีภาพ ซูมด้วยล้อเมาส์ ปุ่ม ＋/－ หรือบีบนิ้ว ลากภาพเมื่อซูมเข้า เปลี่ยนภาพด้วยปุ่มลูกศรหรือแถบภาพย่อ
- รองรับคีย์บอร์ด: `Esc` ปิด และลูกศรซ้าย/ขวาเปลี่ยนภาพ
- รับ prop `preview` (ค่าเริ่มต้น `false`) ถ้าเป็น `true` จะแสดงแค่ 2 โปรเจกต์แรก

### `ContactSection.vue`
ฝั่งซ้ายเป็นช่องทางติดต่อ ฝั่งขวาเป็นฟอร์ม (ชื่อ อีเมล หัวข้อ ข้อความ) ส่งผ่าน EmailJS มีสถานะกำลังส่ง ส่งสำเร็จ และแสดงข้อผิดพลาด

### `Footer.vue`
พื้นหลังสีดำ แสดงโลโก้ เมนูท้ายหน้า ช่องทางติดต่อ ปุ่มโซเชียล และลิขสิทธิ์ (ปี พ.ศ. คำนวณอัตโนมัติ)

## 🎨 ธีมและ Design Tokens

กำหนดไว้ที่ `:root` ใน `App.vue`

```css
--bg-deep       #eef4fb   พื้นหลังหลักของเว็บ (ฟ้าอ่อน)
--bg-card       #ffffff   พื้นหลังการ์ด
--accent        #2563eb   สีหลักของธีม (น้ำเงิน)
--accent-soft   #1d4ed8   น้ำเงินเข้ม
--text-primary  #0f172a   ตัวอักษรหลัก และสีขอบ/เงาแข็งของการ์ด
--text-muted    #64748b   ตัวอักษรรอง
--font-body     'Prompt'  ฟอนต์เนื้อหา (รองรับภาษาไทย)
--font-display  'Syne'    ฟอนต์หัวข้อ
```

**ลักษณะเฉพาะของสไตล์ Neo-Brutalism ที่ใช้ทั้งเว็บ**

- ขอบสีเข้ม 2–2.5px และเงาแข็งไม่เบลอ (เช่น `box-shadow: 6px 6px 0 var(--text-primary)`)
- ปุ่มและการ์ดขยับเข้าหาเงาเมื่อชี้เมาส์ (`translate`)
- ป้ายและกล่องสีพาสเทล (ฟ้า มิ้นต์ เหลือง ลาเวนเดอร์ ชมพู) ใช้ตัวอักษรสีเข้มเพื่อให้อ่านง่าย

## 📱 จุดเปลี่ยนเลย์เอาต์ (Breakpoints)

| เงื่อนไข | สิ่งที่เปลี่ยน |
|---|---|
| กว้าง ≥ 1200px **และ** สูง ≥ 600px | เมนูเป็นแถบด้านข้าง และบัตรพนักงานค้างด้านซ้าย |
| กว้าง < 1200px **หรือ** สูง < 600px | เมนูเป็นแถบด้านบน + แฮมเบอร์เกอร์ และเลย์เอาต์หน้าแรกเป็นแบบมือถือ (บัตรอยู่บน ข้อความอยู่ล่าง ไม่ค้าง) |
| กว้าง ≤ 900px | ฟุตเตอร์และหน้าต่างรายละเอียดผลงานเรียงเป็นแนวตั้ง |
| กว้าง ≤ 640px | การ์ดผลงานเรียงเป็นหนึ่งคอลัมน์ |

> ⚠️ เงื่อนไข `1200px / 600px` ต้องตรงกันทั้งใน **`Header.vue`** และ **`HeroSection.vue`** (และ `App.vue` ที่ปรับ `scroll-margin-top`) ถ้าเปลี่ยนที่หนึ่งต้องแก้ให้ครบ

## 🛠️ วิธีแก้ไขเนื้อหา

### เพิ่มหรือแก้ไขโปรเจกต์
1. วางภาพหน้าจอ `.png` ในโฟลเดอร์ `src/assets/project/<ชื่อโฟลเดอร์>/`
2. เพิ่ม object ใน `allProjects` ของ `ProjectsSection.vue`

```js
{
  id: 'my-project',
  title: 'ชื่อโปรเจกต์',
  category: 'web',                       // 'web' หรือ 'design'
  badge: { text: 'ใช้งานจริง', tone: 'mint' },   // ไม่ใส่ก็ได้ | tone: sun, mint, lav, gold
  summary: 'คำอธิบายสั้นๆ ที่แสดงบนการ์ด',
  desc: 'คำอธิบายเต็มที่แสดงในหน้าต่างรายละเอียด',
  tech: ['Vue 3', 'Go (Gin)'],
  github: 'https://...',                 // ลิงก์ที่ไม่มีให้ลบบรรทัดนั้นออก (github, live, figma, drive)
  images: shots('ชื่อโฟลเดอร์', [
    ['ชื่อไฟล์ไม่ต้องมี .png', 'คำบรรยายภาพ'],
  ]),
}
```

- ถ้าเป็นโปรเจกต์มือถือ ใส่ `device: 'mobile'` เพิ่ม
- ถ้าอยากใช้ภาพอื่นเป็นภาพปกแทนภาพแรก ใส่ `cover: <ลำดับภาพ เริ่มที่ 0>`
- ชื่อโฟลเดอร์และไฟล์ต้องตรงตัวพิมพ์เล็กใหญ่ ไม่เช่นนั้นภาพจะไม่ขึ้น

### เปลี่ยนสีพื้นหลังของแต่ละส่วน
- การศึกษา: `background` และ `box-shadow` ในบล็อก `.edu` (`EducationSection.vue`)
- ผลงาน: `background-color` ในบล็อก `.projects` (`ProjectsSection.vue`)
- Footer: `--f-bg` ในบล็อก `.footer` (`Footer.vue`)

### เปลี่ยนรูปโปรไฟล์บนบัตรและเมนู
แทนที่ไฟล์ `src/assets/akarawit-applyjob.png` (ใช้ทั้งบัตรพนักงาน เมนูด้านข้าง และส่วนอื่นที่ import ไฟล์นี้)

## ⚙️ การติดตั้งและรัน

```bash
npm install
npm run dev        # เปิดเซิร์ฟเวอร์สำหรับพัฒนา
npm run build      # สร้างไฟล์สำหรับ deploy (โฟลเดอร์ dist)
npm run preview    # ทดลองเปิดไฟล์ที่ build แล้ว
```

สร้างไฟล์ `.env` ที่ root ของโปรเจกต์สำหรับ EmailJS

```
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

> ไฟล์ `.env` ต้องอยู่ใน `.gitignore` เสมอ เพื่อไม่ให้ค่าตั้งค่าหลุดขึ้น GitHub ส่วนไฟล์เรซูเม่ให้วางไว้ที่ `public/Akarawit_Resume.pdf` เพราะปุ่มดาวน์โหลดอ้างถึง path นี้
